# Historical snapshot — superseded

Every file in this folder describes an earlier phase of this project (PostgreSQL, then a SQLite migration) that predates the current MongoDB Atlas datastore, the authentication system, the scraper pipeline, and the analytics dashboards. None of it reflects the system as it exists today.

**For current, accurate technical documentation, see [`docs/technical/README.md`](../docs/technical/README.md) instead.**

These files are kept for history rather than deleted — they're a genuine record of the project's earlier design — but should not be relied on for anything about the current architecture, stack, or data model.
